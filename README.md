One funny line, 91 characters:

> I tried to quit coffee, but my coffee maker filed a restraining order against my willpower.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and verifies it by
read-back: byte-identical, pinned sha256, length 1–200, single line, no
trailing newline.
